## 3. 静态与合成契约

`t063_range_tree_static_probe.py` 使用 AST 精确检查配置读取位置，并构造最小 range
tree 验证变换前后表达式。结果位于
`results/t063_range_tree_20260828/static_retry3/result.json`，整体通过。

- strided：`2*x0+1` 被拆成 `2*inner+128*outer+1`，关闭时保持原表达式；
- root modulo：开启时把叶轴映射到 1500 内轴，关闭时只映射 root；
- reduction modulo：`ModularIndexing(r, 1, 1500)` 开启时命中内轴并保留 flat 重构；
- collapse：两个 row-major x 轴折叠成 `% 4` 与 `// 4` 的单一平坦轴映射；
- scalar odometer：主门控与 reduction 子门控的 on/off 返回集合均符合契约。

## 4. NPU 功能矩阵

所有测试均从 `/home/z50063656/tmp` 启动，使用 fresh process、独立 Inductor/Triton
cache，并由 eager 结果校验 generated code。

| 子项 | 运行态覆盖 | 结果 | 门控证据 |
|---|---|---:|---|
| strided pointwise | on/off，`x[1::2]` | 2/2 | on 发生 1 次拆轴，off 为 0 |
| root modulo | on/off，`bias.repeat(39)` + batch bias | 2/2 | on 重定向叶轴且外轴 39；off 映射 root 且外轴 78 |
| reduction modulo | on/off，动态 M=4/6 | 4/4 | scheduler 已预拆 `1500 × M`，作为运行态邻接验证 |
| collapse x-tree | static/dynamic on/off | 6/6 | helper 被调用但布局间隙使自然图合法不折叠；精确变换由合成契约覆盖 |
| scalar odometer | pointwise/reduction on/off | 4/4 | 自然图已分树或 size-1 专门化；精确主/子门控由合成契约覆盖 |

合计 14/14 配置、18/18 eager 对照通过。`strided` 与 `root modulo` 是真实变换
命中；其余子项没有把“helper 被调用但未变换”包装成真实命中，而是明确采用“静态
精确契约 + NPU 运行态邻接”证据。

首次 sandbox 样本保留了 `aclInit 507008` 环境失败；同一用例在授权 NPU 环境通过，
因此该记录不计产品失败。

## 5. 三轮性能对照

只对真实命中的 `split_strided_pointwise` 和 `split_root_modulo` 做 on/off 性能对照。
每个样本 warmup 10、测量 100 次，三轮交换执行顺序。表中正值表示开启门控更快。

| 门控 | device p50 | device p99 | host p50 | host p99 | 编译首跑 | peak |
|---|---:|---:|---:|---:|---:|---:|
| strided | -2.14%（1/3） | +1.83%（2/3） | -0.62%（1/3） | -28.97%（0/3） | -0.59% | 0 B |
| root modulo | +0.08%（2/3） | -10.35%（1/3） | -3.54%（1/3） | -276.59%（0/3） | -0.24% | 0 B |

`root modulo` 的 host 样本存在毫秒级同步离群点，而 kernel 本体约 0.2 ms；不删除
离群样本，也不用 host p99 单独决定门控。device p50 没有一致的大幅回退，编译差异
小于 1%，峰值内存相同。单一最小图不足以推翻默认开启的索引拆分策略，因此保留六个
默认值，并登记 device p99/host tail 监控，不产生产品修改。

## 6. 邻接缺陷与下一步

探索 `split_reduction_modulo` 的总规约图时，默认 `rtree_real_block` 把两个 reduction
轴提升为真实 block，但没有保留 x 轴：

1. 生成的 broadcast guard 引用了未定义的 `xmask`；
2. probe-only 去掉该 conjunct 后，继续暴露 store 的三维值到二维目标的 rank mismatch；
3. on/off `split_reduction_modulo` 都能走到该问题，说明它不属于 T-063 门控本身；
4. 未把 probe-only 猴补写入产品源码。

因此下一项为 T-064 / TE-CG-007：reduction tiling and guard elision，优先复现并修复
zero-kept-x-axis 的 `rtree_real_block` 生成代码，再覆盖 autotune、where elision 与
small-outer flattening。
