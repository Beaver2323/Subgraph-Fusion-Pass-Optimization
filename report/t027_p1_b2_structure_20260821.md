## 判定边界

这些 UT 只构造并变换 FX 图，不运行 NPU kernel。因此矩阵中的 7 条记录只推进为
`structure-trigger-confirmed`，正确性字段表示结构正负例通过；codegen、fallback、
performance 和最终 verdict 仍为 `not-run`。

下一阶段需要为代表 positive/negative 图建立 default backend fresh-process NPU compile
worker，同时捕获 custom pass 前后目标节点、eager/compiled 正确性和设备 task。只有
这层通过后，才讨论单 pass 关闭后的 paired 性能。
