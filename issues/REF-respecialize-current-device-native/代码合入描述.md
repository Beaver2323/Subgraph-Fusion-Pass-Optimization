# fix(triton_experimental): resolve experimental NPU device at runtime for CooR

> 已同步远端 [PR 46465](https://gitcode.com/Ascend/pytorch/pull/46465)，当前为非草稿，提交 `8eb561265599db4da80a8828e461488598645f5a`。CLA 已通过。
> [流水状态与最新提交](../../report/四个PR推送与流水状态_20260921.md)；状态核对时间（UTC）：2026-09-21T02:30:36.335490+00:00。

## 【合入来源】

修复在一个分布式进程中编译、供其他进程使用编译结果时，NPU 设备编号被固定的问题。

## 【修改方案】

PyTorch 的 `compile_on_one_rank` 要求生成代码在运行时获取当前设备。原 NPU 后端缺少 `current_device_idx_expr()`，且 kernel 的 `DeviceProperties` 仍携带编译时设备编号。

- 实现 `current_device_idx_expr()`，生成 `torch.npu.current_device()` 表达式。
- 开启 `compile_on_one_rank` 时，为两处 `DeviceProperties` 构造传入不带编号的 NPU 设备，使编号由运行时解析。
- 普通编译继续保留原设备编号。
