## 关键代码变更

```python
# 修改前：torch/_inductor/codegen/common.py:341（冻结上游，保持不变）
def current_device_idx_expr(self) -> str:
    raise RuntimeError("compile-on-one-rank ... is not supported ...")

# 修改后候选：torch_npu/_inductor/triton_experimental/device.py:56
def current_device_idx_expr(self) -> str:
    return "torch.npu.current_device()"
```

注意返回的是待生成到 wrapper 的 Python 表达式，而不是在编译期调用 `torch.npu.current_device()` 得到一个整数。后者仍会固化编译时卡号，违背合同。

## 修复理由

与 CUDA 的 `current_device_idx_expr()` 采用同一接口合同，但返回 NPU API。现有 NPU `set_device`、`device_guard` 已接受字符串表达式；NPU allocator 使用当前设备。修改限定 experimental 子类，不把其他后端未验证状态一并宣称支持。无显式产品配置 disable；此处是缺少必需接口产生的默认能力拒绝。
