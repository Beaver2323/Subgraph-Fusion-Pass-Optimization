# 【修改方案】

1. 在 `triton_experimental` 激活时，向 post-grad 第 2 轮注册 NPU 专用的
   `div → mul → add` 到 `aten.addcdiv` 重融合 pattern。
2. pattern guard 仅接受已在 910B2 动态验证的 FP32 `self/t1/t2/output`、NPU
   device 和 Python/SymPy scalar；FP16/BF16、tensor-valued scalar 与非浮点
   `self` 均保持不命中。
3. experimental 的统一 fallback 扫描完成后，窄注册
   `aten.addcdiv.default` lowering，使用 `ops.div_rn`，`value != 1` 时使用
   `ops.fma`。
4. 保持冻结 PyTorch 不变，不增加 CPU fallback，不跳过社区断言，也不把整个
   `addcdiv` packet 加入通用生成白名单。
