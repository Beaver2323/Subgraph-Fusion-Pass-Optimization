### 实际代码和对齐边界

```python
# 文件：../REF-sfdp-pattern-21-native/evidence/t106-native-6t1pel2i/adapter/debug/
# torch_compile_debug/run_2026_09_15_10_54_18_778570-pid_2106776/torchinductor/
# model__0_inference_0.0/output_code.py:371-372（实际发射，换行排版）
_es_full0 = tl.load(in_ptr0 + (2 * x2 + 128 * x3) + _es_lane0,
    x2mask & x3mask & ((2 * x2 + 128 * x3 + _es_lane0 >= 0)
    & (2 * x2 + 128 * x3 + _es_lane0 < 256)), eviction_policy='evict_last')

    [_es_full0.shape[0], _es_full0.shape[1], 1], [1, 1, 1])
```

23号实际 `output_code.py:60` 调用 `torch.ops.npu.npu_fusion_attention_v3.default`；
