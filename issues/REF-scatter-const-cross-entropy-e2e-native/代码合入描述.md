# T-080 Codegen 修复合入描述

> 更新时间：2026-09-07 20:20 CST（UTC+08:00）

## 变更目的

修复 `triton_experimental` 在 large-grid CrossEntropy backward 上的两处通用 codegen 缺口：

1. `auto_blockify_size` 从 AST constexpr 分层到 Ascend `NPUOptions`；
2. group-dispatch 的零初始化改为 typed scalar，避免物理 rank 后扩展造成广播失败。

## 影响文件

```text
torch_npu/_inductor/triton_experimental/npu_triton_heuristics.py
torch_npu/_inductor/triton_experimental/codegen/triton.py
```

不修改 PyTorch Scatter pattern，不扩大其支持范围。两项变更由社区完整
Linear→CrossEntropy→backward shape 触发，并在相同 `triton_experimental` 后端的 OFF/ON fresh process
中验证。详细代码、必要调用栈和边界见同目录《根因分析》，结果见《修复验证报告》。

产品仓库是共享脏工作树；`triton.py` 含其他已有变更，合入时只能挑选本报告所列 typed-zero hunk，
不能把无关 diff 一并归属到 T-080。
