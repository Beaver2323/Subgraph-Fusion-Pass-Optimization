# T-080 完整 Scatter Benchmark 根因分析

> 更新时间：2026-09-07 20:20 CST（UTC+08:00）
>
> 后端：`triton_experimental`

## 1. 现象与首个分歧

小 shape 的 8 个功能合同全部通过，但社区 `DO_PERF_TEST=1` 的完整
`B=32,T=1024,D=768,V=50257` BF16 CrossEntropy backward 在性能计时前编译失败。失败位于
`nll_loss_backward` 生成 kernel 的 codegen/autotune，不在 Scatter pattern 的匹配或 replacement。

首个异常：

```text
ValueError: 'auto_blockify_size' is not in list
```

修复后继续前进，第二个异常才显露：

```text
Cannot broadcast, rank mismatch: [1], [1, 24576]
```

## 2. 必要调用栈

```text
test_scatter_optimization.py::TestScatterOpt.test_cross_entropy_loss
  -> t080_performance_worker.py::scatter_workload
  -> torch.compile(fn)
  -> compile_fx._recursive_post_grad_passes
  -> joint_graph.scatter_upon_const_tensor（ON；OFF 不进入）
  -> GraphLowering / NPUTritonKernel codegen
  -> NPUCachingAutotuner._precompile_config
  -> triton.compile(ASTSource, NPUOptions)
  -> ValueError(auto_blockify_size)
```

第二条路径是：

```text
GraphLowering
  -> NPUTritonKernelOverrides.constant
  -> logical triton_tensor_ndim() == 1
  -> group-dispatch 把物理 tile 展开为 [1, XBLOCK]
  -> tl.full([1], 0) 与 [1, XBLOCK] store mask 无法广播
```

## 3. 根因一：编译选项误入 AST 常量

原实现把 `Config.kwargs` 全量并入 `compile_meta["constants"]`。但 `auto_blockify_size` 是 Ascend
compiler option，不是生成 Triton 函数签名中的 constexpr 参数；Triton 因而在 `fn.arg_names` 中
查找一个不存在的名字。

```python
# torch_npu/_inductor/triton_experimental/npu_triton_heuristics.py
# 修复前
cfg_kwargs = cfg.kwargs
compile_meta["constants"].update(cfg_kwargs)
```

最小修复只把该键从 AST 常量分层到 `NPUOptions`：

```python
# torch_npu/_inductor/triton_experimental/npu_triton_heuristics.py::_precompile_config
cfg_kwargs = dict(cfg.kwargs)
auto_blockify_size = cfg_kwargs.pop("auto_blockify_size", None)
compile_meta["constants"].update(cfg_kwargs)
...
if auto_blockify_size is not None:
    options["auto_blockify_size"] = auto_blockify_size
```

## 4. 根因二：逻辑 rank 与物理 rank 生命周期错位

零初始化在查询逻辑 ndim 后生成 shaped zero；group-dispatch 随后才扩展物理 rank。typed scalar zero
本身可广播到任意物理 tile，且零仅用于 output initialization，因此无需把 rank 固化在常量表达式里。

```python
# torch_npu/_inductor/triton_experimental/codegen/triton.py
class NPUTritonKernelOverrides(TritonKernelOverrides):
    @classmethod
    def constant(cls, value, dtype):
        ndim = V.kernel.triton_tensor_ndim()
        if ndim == 0:
            return TritonOverrides.constant(value, dtype)
        if value == 0:
            return TritonOverrides.constant(value, dtype)
        ...
```

## 5. 修复边界

- 不修改 `scatter_upon_const_tensor_extra_check`，不放宽 shape/density/base/dtype guard。
- 两处修复对 OFF/ON 两臂同时生效；性能对照只切换目标 Scatter pass。
- 不把其他 backend 或小 shape 的成功记录转写成完整社区图结论。
- `triton.py` 共享工作树还有其他既有改动；本单元归属仅为 typed-scalar zero 分支，提交前须做
  精确 diff 归属审查。
