## 2. 最小适配

入口为本目录 `npu_adapter.py`，共用 `runners/module_folding_community_npu.py`。
仅适配原类发现及 `self.device`；原方法、参数乘积、断言、容差均不变。
handler 只读观察前后 FX，`product_gate_bypassed=false`，实际后端为 `triton_experimental`。

## 3. 必要调用链

原unittest → torch.compile/pre_grad → efficient_conv_bn_eval_graph_transform_inlined或decomposed
→ AOTAutograd → NPU codegen → 原输出/SGD后输出/counter断言。
原tf32_on_and_off装饰器保留：NPU无CUDA TF32支持，执行一次112组合，不伪装CUDA硬件。每组有前向、SGD后前向两次数值比较；CUDA TF32双臂合计224组合，不能与单模式混算。
原方法没有逐参数梯度assert；SGD后输出是间接梯度证据，不能写成全部梯度逐元素已对齐。

## 4. 结果与边界

只有原类发现及self.device最小适配；handler只读观察前后FX，不改shape/dtype/循环/断言/产品gate。
