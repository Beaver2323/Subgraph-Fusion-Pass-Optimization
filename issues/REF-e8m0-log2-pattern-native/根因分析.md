## 测试目的与根因类型

社区优化在正、正规 FP32 输入上直接读取 IEEE 754 指数与尾数，解决 log2+ceil 在 2 的幂邻域错一档的问题。

## 2026-09-11 18:19 安装前数值域复核

用户已授权继续部署与安装态回归。此前候选只检查设备/dtype，无法从 tensor metadata 证明输入全是正的正规数，因此不能原样接入产品。
新增实际诊断 `/home/z50063656/tmp/t096-domain-baseline-UNxCWd/artifacts/result.json`：负值、NaN、正负零的原 NPU eager/compile 编码均为 0，正无穷为 254；原位运算候选对 -1/NaN 不保持这些结果。
在 `0x00400001`（2^-127 上方 1 ULP）和 `0x00800001`（最小正规数上方 1 ULP）还发现原 eager/compile 分别为 0/1，数学编码应为 1/2。

修复在独立工作树 `torch_npu_t096_e8m0` 的 `triton_experimental/e8m0.py` 中补充：指数为零时仅 mantissa > 2^22 编码为 1；负数/NaN 编码为 0；正无穷饱和至 254。正常正值仍用社区 pre-SM100 的指数加尾数进位公式。
通过 experimental 后端激活入口自动注册，并添加 `enable_e8m0_rceil_log2` 精确开关；不依赖测试 monkey-patch、不改 frozen PyTorch、不扩展到 FP16/BF16。
这比社区已验证范围更宽，必须另记 NPU 边界扩展，不能声称这些额外边界已做 CUDA 实测。当前仍待新源码部署及回归。

## 18:44 产品修复与最终根因判定

根因分类为 **behavior-mismatch**：上游只有 CUDA 注册，NPU 没有对应 replacement，因此仍执行有限精度的 software log2。2 的幂上方 1 ULP 被舍入到整数后，ceil 无法恢复丢失的信息。
不是 NPU Triton 编译器不能执行整数位运算：新生成的位掩码/where kernel 与 NPU extern 组合已真机通过。未修改 Triton 编译器、PyTorch 或 eager log2 实现。

```text
# 修复后调用链：torch_npu/_inductor/triton_experimental/__init__.py::_activate
experimental 激活 → e8m0.register_e8m0_pattern()
 → post_grad.pass_patterns[1] 中独立 NPU replacement
 → e8m0_extra_check：NPU + FP32 + enable_e8m0_rceil_log2
 → e8m0_rceil_log2_replacement
 → NPU view(dtype)/rshift extern + Triton mask/where kernel
 → 原 uint8 数学编码断言（不放宽为 eager 一致）
```

```python
# 产品文件：torch_npu/_inductor/triton_experimental/e8m0.py:19，核心节选
bits = inp.view(torch.int32)
exponent = (bits >> 23) & 0xFF
mantissa = bits & 0x7FFFFF
normal = torch.clamp(exponent + (mantissa != 0).to(torch.int32), 0, 254)
subnormal = (mantissa > 0x400000).to(torch.int32)
encoded = torch.where(exponent == 0, subnormal, normal)
invalid = (bits < 0) | ((exponent == 0xFF) & (mantissa != 0))
return torch.where(invalid, 0, encoded).to(torch.uint8)
```

非正规数只有 `mantissa > 2^22` 才跨过未被 clamp 饱和的 `2^-127` 编码边界。负值/NaN保留已测NPU旧行为0，正无穷饱和254；FP16/BF16/CPU仍不命中。
默认开启此精确修复是为保持原数学合同，不是根据性能启用原有显式关闭优化。完整[三文件源码差异](e8m0_installed_source.patch)基于项目83cc45248，局部分支 `fix/t096-e8m0-20260911` / 提交 `6408f950c`，尚未推送或社区合入。
