# T-096 E8M0 安装态修复验证报告

> 更新时间：2026-09-11 18:44 CST（UTC+08:00）。Pass / triton_experimental；正确性修复通过，局部性能回退。

## 问题描述

原安装态没有 NPU E8M0 replacement，普通向量数值对但未改图；one-ULP与gh178045原数学断言分别5/8、4/7项错误。这里eager和compiled同时错，不可用两者一致替代数学oracle。
调用栈、第一处分歧、保留的候选阶段和硬红线检查见[根因分析](根因分析.md)。

## 修复内容摘要

新增 `experimental/e8m0.py`，后端激活时自动注册，精确配置 `enable_e8m0_rceil_log2=True`。FP32指数/尾数公式复用社区pre-SM100思路，另补NPU特殊值及非正规数保护，不伪造CUDA能力、不替换原测试断言、不依赖测试注入候选。

```python
# torch_npu/_inductor/triton_experimental/e8m0.py:19，语义节选
bits = inp.view(torch.int32)  # reinterpret，保留IEEE754位域
exponent, mantissa = (bits >> 23) & 255, bits & 0x7FFFFF
normal = torch.clamp(exponent + (mantissa != 0).int(), 0, 254)
encoded = torch.where(exponent == 0, (mantissa > 0x400000).int(), normal)
invalid = (bits < 0) | ((exponent == 255) & (mantissa != 0))
return torch.where(invalid, 0, encoded).to(torch.uint8)
```
