## 实际失败

旧微图采用同编号 half inference 注册。NPU 5、experimental、新进程仅删除1号注册后，观察器捕获 `_sfdp_pattern_3_half_inference` 实际改图，最终仍调用 NPU fusion-attention。数值比较通过后，严格 OFF 门禁报 `RuntimeError: OFF仍命中fuse_attention`，进程退出1，没有计时。

[失败运行原件](evidence/functional-20260915T193905+0800-inference-off/)保留 stderr、精确目标前后 FX、IR 和 output_code。3号推理将 dropout 变为0，因此可承载1号相同的无 dropout 推理图。这不是新增的数值缺陷，也不应通过关闭邻接来造出单编号收益。

```python
# 实际 output_code.py 调用结构（完整参数见上方归档）
torch.ops.npu.npu_fusion_attention_v3.default(
    arg1_1, arg0_1, arg2_1, 4, 'BNSD', None, None, None, 0.5,
    keep_prob=1.0, ...
)
```

只计训练前向，不含 backward、首次编译或模型端到端。原方法前向/梯度验证另外绑定安装态完整原例。OFF仍只移除本编号；若其他attention接替或数值不符，仍拒绝计时。没有移植T-106 pattern21的用户特许处置，没有关闭整轮joint或旁路产品禁用项。
