## 社区合同与最小适配

```python
# PyTorch 8e86e0a: torch/_inductor/fx_passes/fuse_attention.py:1014
if scale_factor_op is not None:
    scale_factor_node = filter_nodes(match.nodes, scale_factor_op)[0]
    scale_factor = scale_factor_node.args[1]
    if not isinstance(scale_factor, (float, int)):
        return False
```

`_get_sfdp_patterns` 的 `c_inp=torch.tensor(2.0, device=...)` 仅用于生成匹配图，不是可直接照搬的运行合同。原适配仅认识参数名 `inv_scale`，遗漏2/4的 `scale_factor` 和3的 `inv_scale_factor`。

```python
# runners/t102_t107_attention_performance_worker.py::normalize_scale_argument
if name in ('inv_scale', 'scale_factor', 'inv_scale_factor') and getattr(value, 'ndim', None) == 0:
    number = value.item()  # 编译/计时之外，同值Python标量
    if type(number) not in (float, int):
        raise ValueError('scale占位不是数值标量')
    return number
```

仅在具名scale参数且零维时转换；mask和其他Tensor不变。实际原值、输入类型写入结果/gate，OFF/ON一致；无修改 `extra_check`、不把真正tensor-scale负例变正例。安装部署边界的tensor-scale负例依旧不命中。

2号失败实测已确认；3/4按同一源码参数映射补齐，不冒称已实测同样失败。1号已签gate使用其冻结执行器，后续公共worker编辑不会污染旧门禁。
