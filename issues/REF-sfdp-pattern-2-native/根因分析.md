```python
# evidence/t102-native-xlrlulf8/adapter/registration-candidate/target-_sfdp_pattern_2_training.py
matmul_backward = torch.ops.aten.matmul_backward.default(tangents_2, div, primals_6, [True, True])
```

实际 NPU 梯度图含 `matmul_backward` 和 mul/sub softmax 梯度，与 CUDA 预生成训练注册不同。保留这些设备分解、重建同一 search 的 pattern 后完整原方法通过。
