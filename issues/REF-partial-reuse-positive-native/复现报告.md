失败日志：
`/home/z50063656/tmp/t078-npu-results/REF-partial-reuse-positive-native/adapter-vu9xnf5s/`。

关键异常：

```text
NoTritonConfigsError: No valid triton configs
tmp2 = triton_helpers.min2(_tmp2, 0)[None, :]
TypeError("min() got an unexpected keyword argument 'propagate_nan'")
```

图模式证据确认 pass 已生效：失败分支的 `fx_graph_readable.py` 原为两条独立 reduction：

```python
amin = torch.ops.aten.amin.default(arg0_1, [0], True)
min_1 = torch.ops.aten.min.default(arg0_1)
```

`fx_graph_transformed.py` 已变为：

```python
amin_default = torch.ops.aten.amin.default(arg0_1, [0], True)
min_default = torch.ops.aten.min.default(amin_default)
```

因此这不是 pattern 未命中；失败发生在改写后的 `amin` reduction codegen/compile。

## 初步判断

`triton_experimental` 的 `npu_triton_helpers.min2` 使用了当前 Triton Ascend 不支持的
`tl.min(..., propagate_nan=True)` 调用形式。进入 diagnose，修复面应限定在该 helper，
不能撤销 partial reuse、关闭测试或改写测试输入。
