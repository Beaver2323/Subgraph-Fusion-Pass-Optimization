# 【修改方案】

1. 保留 `triton_experimental` 对 `triton_helpers.min2` 的 NPU override。
2. 将 Triton Ascend 3.2.0 不支持的 reduction `tl.min(..., propagate_nan=True)`
   改为 `tl.reduce`。
3. reduction combine 使用
   `tl.minimum(..., propagate_nan=tl.PropagateNan.ALL)`，保持 PyTorch `amin` 的
   NaN 传播合同。
4. 不修改 partial reuse pattern、4096 阈值、社区 shape、断言或冻结 PyTorch。

# 【接口与资料变更】

不涉及客户可见 Python/C++ API；只修复 experimental 内部 Triton helper。tracker 中
增加中文复现、根因、验证和合入说明。
