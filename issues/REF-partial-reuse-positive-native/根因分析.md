## 根因分类

`behavior-mismatch`：torch_npu experimental reduction helper 与当前 Triton Ascend API
不兼容。不是 eager 算子缺失、partial reuse pattern 缺失、显存问题或 CPU fallback。

## 根因链路

1. 上游 `reuse_partial` 已把 `full(x)` 改成 `full(partial(x))`；三个正例的 transformed
   FX 都能看到这一结构。
2. `amax` 两个分支能完成编译并通过 counter/数值断言。
3. `amin` 分支生成 `triton_helpers.min2(_tmp2, 0)`。
4. `torch_npu/_inductor/triton_experimental/npu_triton_helpers.py` 在模块加载时覆盖
   PyTorch runtime helper，旧实现为：

   ```python
   # torch_npu/_inductor/triton_experimental/npu_triton_helpers.py:33
   @triton.jit
   def min2(a, dim):
       return tl.min(a, dim, propagate_nan=True)
   ```

5. 当前 Triton Ascend 3.2.0 的 reduction `tl.min` 签名不接受
   `propagate_nan`，故所有 autotune config 在同一 AST 调用点编译失败。逐元素
   `tl.minimum` 则支持 `tl.PropagateNan.ALL`，也可作为 `tl.reduce` combine。

## 最小修复

只修改一个此前 clean 的 torch_npu 文件：
`torch_npu/_inductor/triton_experimental/npu_triton_helpers.py`。

```python
# torch_npu/_inductor/triton_experimental/npu_triton_helpers.py:33
@triton.jit
def minimum(a, b):
    return tl.minimum(a, b, propagate_nan=tl.PropagateNan.ALL)


@triton.jit
def min2(a, dim):
    return tl.reduce(a, dim, minimum)
```

该实现镜像冻结 PyTorch `torch/_inductor/runtime/triton_helpers.py` 的 reduction
方法：使用支持的逐元素 combine，同时保留 PyTorch `amin` 的 NaN 传播语义。
