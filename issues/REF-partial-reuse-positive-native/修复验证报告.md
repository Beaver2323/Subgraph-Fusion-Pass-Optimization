## 问题与修复摘要

T-078 partial reduction reuse 的三个社区正例均成功发生 FX 改写，但修复前
`amin→min` 在 experimental `min2` 编译处失败。修复将不兼容的
`tl.min(..., propagate_nan=True)` 改为
`tl.reduce(..., tl.minimum(..., PropagateNan.ALL))`，不改变 pass、输入或断言。

## 图结构核验

三个正例的 transformed FX 都从“两条 reduction 同时读取原 x”变为“full reduction
读取 partial 结果”。例如 `amin→min`：

```python
# before
amin = torch.ops.aten.amin.default(arg0_1, [0], True)
min_1 = torch.ops.aten.min.default(arg0_1)

# after
amin_default = torch.ops.aten.amin.default(arg0_1, [0], True)
min_default = torch.ops.aten.min.default(amin_default)
```

这证明优化在 autotune/codegen 之前已生效；修复只是使其生成的 min reduction 能被
Triton Ascend 正确编译。
