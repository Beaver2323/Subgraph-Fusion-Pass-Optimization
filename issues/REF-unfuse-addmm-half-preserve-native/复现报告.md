## 测试合同

`test/inductor/test_pattern_matcher.py::TestPatternMatcher.test_unfuse_bias_addmm_half_dtypes`，
参数为 `torch.bfloat16`、`torch.float16`。冻结 PyTorch commit 为
`8e86e0a23e3679c2bf3406cf0837fcb6297a5d9b`。

社区测试显式设置 `keep_addmm_fused_for_half_dtypes=true`。由于把 half addmm 拆成
mm 与 pointwise bias 可能在 mm 输出处多一次截断，NPU（非 XPU narrowing-cast 特例）
必须保留 fused addmm。原断言要求 generated code 包含 `extern_kernels.addmm`。

GPU 紧凑 reference 的两个参数分支均通过。
