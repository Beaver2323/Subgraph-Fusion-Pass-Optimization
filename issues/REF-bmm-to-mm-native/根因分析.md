## 测试目的

社区用例验证 batch=1 的 `aten.bmm` 会在 GPU 上改写为
`squeeze → aten.mm → unsqueeze`，而 batch>1 保留 `aten.bmm`。NPU 功能适配保留了原 shape、数值断言、
counter 和 FileCheck；性能阶段进一步判断这项 GPU 侧合法改写在 NPU 上是否值得启用。

## 根因类型

`behavior-mismatch`：不是数值或算子能力错误，而是上游通用 GPU rewrite 被 NPU 继承后形成了错误的
后端盈利性选择。

## 图模式第一现场与调用栈

`TORCH_COMPILE_DEBUG=1` 证明 OFF 四张图均调用 `extern_kernels.bmm`，ON 四张图均调用
`extern_kernels.mm`；目标命中数分别为 0 和 4。`lowering_override_list.py` 同时包含 `aten.mm` 和
`aten.bmm`，不存在 CPU fallback、缺失 lowering、dtype/layout 转换或 Triton 编译失败。

```python
# OFF: workers/off1/.../output_code.py:60
extern_kernels.bmm(arg0_1, arg1_1, out=buf0)

# ON: workers/on1/.../output_code.py:60
extern_kernels.mm(
    reinterpret_tensor(arg0_1, (16, 8), (8, 1), 0),
    reinterpret_tensor(arg1_1, (8, 32), (32, 1), 0),
    out=buf0,
)
```

必要调用链如下；第一个后端分歧发生在 joint-graph pattern 的设备判定处：

```text
TestPatternMatcher.test_bmm_to_mm
  -> torch.compile
  -> torch_npu.utils._dynamo.register_inductor_npu
  -> torch_npu._inductor._load_triton_experimental_backend
  -> triton_experimental._activate
  -> overrides.apply_npu_overrides
  -> joint_graph.patterns.apply
  -> joint_graph.py::bmm_to_mm
     -> check_device(..., get_gpu_type())
     -> match.replace_by_example(squeeze -> mm -> unsqueeze)
  -> Inductor lowering
  -> NPU extern_kernels.mm / extern_kernels.bmm
```

```python
# PyTorch: torch/_inductor/fx_passes/joint_graph.py::bmm_to_mm
if (
    check_device(mat1.meta["val"], mat2.meta["val"], get_gpu_type())
    and statically_known_true(mat1.meta["val"].shape[0] == 1)
):
    match.replace_by_example(repl, [mat1, mat2])
```

torch_npu 的 `patch_is_gpu()` 会令通用 GPU 类型集合包含 NPU，因此 NPU 自动继承该 CUDA 导向 rewrite。
语义等价不代表后端盈利；当前 NPU extern `bmm` 在全部实测子域都快于 rewrite 后的 extern `mm`。

## NPU 能力匹配评估

NPU 同时支持 `aten.bmm` 与 `aten.mm` lowering，两条图都能正确生成和执行。因此这是“能力已具备、
盈利性不匹配”，不是 missing-dispatch。产品处置应默认保留更快的 bmm，并允许未来基于新硬件或更细
shape 策略重新打开。

```python
def gated_extra_check(match, _original_check=original_check):
    output = match.output_node().meta.get("val")
    is_npu = (
        getattr(getattr(output, "device", None), "type", None) == "npu"
    )
    if ncfg.disable_bmm_to_mm and is_npu:
        return False  # ← NPU 默认保留 bmm
    return _original_check(match)  # ← CPU/CUDA 与显式重新开启时保持上游语义
```

## 修复理由

回退只出现在 torch_npu 的 `triton_experimental` NPU 后端；上游 CUDA 合同和代码没有错误。修复放在
torch_npu backend 激活生命周期内，既不修改冻结 PyTorch，也不把 NPU 盈利性策略扩散到 CPU/CUDA、
default、DVM 或 MLIR 后端。
