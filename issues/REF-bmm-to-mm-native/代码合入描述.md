# 【修改方案】

1. 在 `triton_experimental/config.py` 新增默认开启、可逆的 `disable_bmm_to_mm` 门禁。
2. 在 backend 激活时定位上游 joint-graph 的 `bmm_to_mm` entry，并包装其 `extra_check`。
3. 仅当 match 输出设备为 NPU 且门禁开启时拒绝 rewrite；其他设备透传原 predicate。
4. 新增 UT 看护 NPU-only、显式重新打开和重复安装幂等性。

根因是 NPU 继承上游通用 GPU rewrite 后出现稳定性能回退，不是上游功能错误，因此修复放在 torch_npu
experimental backend，不修改 PyTorch。
